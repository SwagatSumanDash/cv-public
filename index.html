CV Uploader

Upload a PDF CV or a generated HTML CV, publish it to GitHub Pages, and copy the shareable link into Google Sheets.

Important — public links: files uploaded here become public. Anyone with the link can view, download, and forward the CV. Do not upload CVs unless you are permitted to publish them publicly.

1. Connect to your GitHub repository

Create a fine-grained Personal Access Token that has access only to SwagatSumanDash/cv-public, with Contents: Read and write permission. Metadata read access is usually granted automatically.

Create a fine-grained token on GitHub. Set an expiry, select only the cv-public repository, and do not share the token.

The token is not saved by this page or written into the repository. It remains in this browser tab's memory while the page is open. Clear it or close the tab when finished.
